title: Subscription Business
description: Administrators manage plans and node groups. Customers can create
  and cancel their own orders. Amounts are integer CNY cents. Only
  administrators can confirm offline receipts and retry service delivery.
  Renewals preserve measured traffic. Failed delivery retains its fixed expiry
  target for idempotent retries.
